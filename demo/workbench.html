03 / TRY LIVE AUTHORING

Keep the story. Edit the UI.

1 / MAKE IT YOURS

Type a name and equip the lantern. Accept a quest. Your state lives in WorkbenchViewModel.cs, not in the markup.

2 / CHANGE THE ACCENT

In demo/workbench.css, change --accent from #b9e38c to #eebd78. Save. Keep the name field focused and press F7.

CSS reload keeps the same DOM: value, caret, selection and focus survive. Or explicitly turn on Watch sources.

3 / REPLACE THE MARKUP

Edit this heading in demo/workbench.html (keep the control IDs). Press F8 to force replacement, even without an edit.

Model state survives; C# restores form values and rebinds controls. Focus starts anew. Record another finding to try a rebound handler.

4 / FAIL SAFELY

Temporarily add body { display: grid; } to the CSS and press F7. Grid is not supported: reload is rejected, an error explains why, and this UI keeps working. Remove the rule and reload.

Author within the supported profile

The generated docs/capabilities.md distinguishes parser acceptance from actual layout, paint and input support. This is not a browser: no JavaScript, grid, templates or automatic two-way binding.
